These user-provided captures were selected from the `hyprsnip_*` screenshots
dated November 13, 2026. They show actual CeFont terminal output. Their
pixels are unedited: no generative changes, cropping, recoloring, or synthetic
light-mode variants were applied. README display sizes preserve the original
aspect ratios and do not upscale the captures.

The capture filenames, dimensions, visible content, and SHA-256 hashes are
recorded below. Hashes were checked against the original files before commit.
No unrelated desktop/browser captures or title-only fragments were included.

terminal-font mutation, recovery, or compatibility with every terminal.
